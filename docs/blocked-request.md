# Help with a blocked request

whenkat.com uses a security filter to stop suspicious requests. Sometimes it can
block an ordinary visit by mistake.

Try opening [the homepage](https://whenkat.com/) directly. If the problem keeps
happening, [start a Q&A discussion](https://github.com/pycaster/whenkat.com/discussions/new?category=q-a)
and include:

- The **request ID** shown on the block page.
- The approximate time of the block, including your time zone.
- The page you were trying to visit and what you were doing.

GitHub requires an account to post. Discussions are public: share only the page
path, leaving out query strings or anything personal. You do not need to post
cookies, passwords, tokens, or your IP address.

A report helps me find the security event and check whether the filter needs an
adjustment. Reporting a block does not automatically allow the request.
