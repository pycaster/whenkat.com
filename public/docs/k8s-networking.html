K8s Cluster Network Topology

proxmox-k8s · Talos + Cilium on 192.168.20.0/24

LAN Physical topology

All VMs run on a single Proxmox host (pve). Each K8s node VM gets a static IP on the LAN via cloud-init. GPUs are passed through via VFIO-PCI.

Pod and Service IPs are virtual — they exist only inside the cluster. Cilium's eBPF programs route packets between all three spaces. Node IPs must be unique LAN addresses for VXLAN tunnels to work.

Kubelet injects nameserver 10.96.0.10 into every pod's /etc/resolv.conf. CoreDNS watches the kube-api for Service/Endpoint changes and serves name.namespace.svc.cluster.local → ClusterIP records. Cilium replaces kube-proxy entirely — Service routing is done in eBPF, not iptables.

L2 External access (LoadBalancer)

Cilium L2 Announcements replace MetalLB. When a type: LoadBalancer Service is created, Cilium assigns an IP from the pool and responds to ARP on the LAN. External clients reach the Service at that IP without any router config.

L7 Gateway API — HTTP routing

Gateway API is the successor to Ingress. A single Gateway can serve many HTTPRoute resources across namespaces. The gatewayClassName field selects which controller (NGINX or Cilium/Envoy) handles the traffic — change it, push, and ArgoCD switches the L7 provider. Both controllers are installed; only the selected one processes the Gateway.

Stack Networking layers

L3/L4 — Cilium

CNI (pod networking), kube-proxy replacement (eBPF Service routing), VXLAN tunnels between nodes, L2 LoadBalancer announcements, network policy enforcement.

DNS — CoreDNS

Cluster DNS at 10.96.0.10. Resolves svc.cluster.local names to ClusterIPs. Injected into every pod by kubelet. Forwards non-cluster queries to 192.168.20.2 (AdGuard).

L7 — Gateway API

Two providers installed: NGINX Gateway Fabric (default) and Cilium/Envoy. Switch via gatewayClassName in the Gateway resource. HTTP host/path routing, TLS termination, cross-namespace routes.

TLS — cert-manager

Automated Let's Encrypt certificates via DNS-01 challenge. Provisions wildcard certs for Gateway listeners.
